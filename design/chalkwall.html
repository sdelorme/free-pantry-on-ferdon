Free Pantry on Ferdon — chalkwall

Candy Chang's wall, translated. The board is a chalkboard with a stencilled fill-in-the-blank prompt; every card completes the sentence in the headline. Chalk texture and the stencil face carry the analog reference, but the answers are set in clean type — one handwriting font across every card would put the same hand on every person, which the eye reads as fake.

The question on the table: how much lift. Both phones are the same board, same content, same colours. Only the elevation and the geometry change.
